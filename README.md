# 🤖 بوت التوظيف السعودي

بوت تليجرام ذكي لمساعدة الباحثين عن عمل في المملكة العربية السعودية.

---

## 🚀 طريقة التشغيل

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. إنشاء بوت تليجرام
- افتح @BotFather في تليجرام
- أرسل `/newbot`
- اتبع الخطوات واحصل على **TOKEN**

### 3. إعداد الإعدادات
افتح `config/settings.py` وعدّل:
```python
BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ"  # ← توكن البوت
CHANNEL_ID = "@your_jobs_channel"                       # ← معرف القناة
```

### 4. إضافة البوت للقناة
- اذهب لإعدادات القناة
- أضف البوت كـ **Admin** مع صلاحية قراءة الرسائل

### 5. تشغيل البوت
```bash
python main.py
```

### متغيرات البيئة

يحتاج التشغيل إلى:

```text
BOT_TOKEN              توكن Telegram من BotFather (مطلوب)
CHANNEL_ID             رقم أو معرف قناة الوظائف (اختياري بقيمة افتراضية)
ADMIN_ID               رقم حساب المشرف (اختياري)
GROQ_API_KEY           مفتاح Groq للتحليل الذكي (اختياري؛ توجد مطابقة محلية احتياطية)
MATCH_THRESHOLD        أقل نسبة مطابقة لإرسال التنبيه، الافتراضي 55
```

## الخدمات والاشتراكات

يتضمن البوت الآن طبقة خدمات قابلة للتوسع:

- حساب مجاني مع رصيد بداية.
- باقات بداية واحترافية ومميزة.
- نقاط عامة مع سجل إضافة وخصم وإرجاع.
- حدود مستقلة للتقديمات والتواصل مع الشركات.
- شاشة الرصيد، الباقات، وتاريخ النقاط داخل Telegram.
- فحص الرصيد قبل التقديم التلقائي ومنع التقديم المكرر.
- خصم الرصيد بعد حجز العملية وإرجاعه إذا فشل إرسال البريد.
- زر تقديم يدوي يفتح بريد التوظيف مباشرة عند توفره.

طلبات الباقات المدفوعة تُسجل بحالة `pending` حتى يتم ربط مزود دفع حقيقي. لا يتم تفعيل اشتراك مدفوع أو خصم مبلغ دون تأكيد دفع من مزود خارجي.

## المطابقة الذكية

تتم مطابقة الوظيفة مع الملف الشخصي عبر الموقع، المجال، التخصص الدقيق، نوع الدوام، الخبرة والراتب. تصل للمستخدم نسبة المطابقة وأسبابها، ويمكن رفع أو خفض `MATCH_THRESHOLD` حسب جودة الإعلانات.

## ⚙️ متغيرات البيئة (Environment Variables)

| المتغير | مطلوب | الوصف |
|---|---|---|
| `BOT_TOKEN` | ✅ | توكن البوت من @BotFather |
| `ADMIN_ID` | مستحسن | معرفك في تليجرام. بدونه تكون لوحة `/admin` **مغلقة على الجميع** وتُعطّل تقارير الأخطاء |
| `CHANNEL_ID` | ➖ | معرف قناة الوظائف |
| `ENCRYPTION_KEY` | مستحسن | مفتاح Fernet لتشفير كلمات مرور تطبيقات الإيميل. بدونه يُشتق مفتاح من `BOT_TOKEN` |
| `WEBHOOK_URL` | ➖ | عند تحديده يعمل البوت بوضع Webhook بدل Polling |
| `WEBHOOK_SECRET` | ➖ | توكن سري يتحقق منه تليجرام مع كل Webhook |
| `PORT` | ➖ | منفذ خدمة الفحص الصحي / الـWebhook (افتراضي 8080) |
| `LOG_LEVEL` | ➖ | مستوى السجلات (INFO افتراضياً) |
| `DB_PATH` | ➖ | مسار قاعدة بيانات SQLite |

توليد مفتاح تشفير:
```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

## 🛡️ تحسينات الجاهزية للإنتاج

- **إصلاح ثغرة أمنية:** كانت لوحة `/admin` مفتوحة لكل المستخدمين إذا لم يُضبط `ADMIN_ID`.
- **معالج أخطاء عام:** رسالة عربية مهذبة للمستخدم + تقرير تفصيلي للمشرف، وتجاهل الأخطاء غير المؤثرة مثل «الرسالة لم تتغير» و«الزر قديم».
- **تشفير كلمات مرور الإيميل** قبل حفظها في قاعدة البيانات (مع دعم البيانات القديمة).
- **حفظ حالة المحادثة على القرص** (`PicklePersistence`)، فلا يفقد المستخدم خطوات التسجيل عند إعادة تشغيل البوت.
- **أمر `/cancel`** للخروج من أي خطوة عالقة.
- **قائمة أوامر رسمية** داخل تليجرام (`setMyCommands`) + إشعار المشرف عند التشغيل.
- **تهريب رموز Markdown** في أسماء وبيانات المستخدمين لتجنّب رسائل مكسورة.
- **تقوية SQLite:** وضع WAL ومهلة انتظار 30 ثانية لتقليل أخطاء «قاعدة البيانات مشغولة».
- **معالجة متزامنة للتحديثات** (`concurrent_updates`) لسرعة أعلى مع عدد مستخدمين أكبر.
- **دعم Webhook** للاستضافة الدائمة، مع بقاء Polling كخيار افتراضي.
- **خدمة `/health`** مرتبة، وخيط خلفي daemon لا يعيق إيقاف البوت.
- **`.gitignore`:** إخراج قاعدة البيانات والسجلات من المستودع (كانت تحتوي بيانات مستخدمين حقيقية).
